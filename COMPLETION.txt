================================================================================
                      TROUBLESHOOTING
================================================================================

"relation does not exist" error
  → Run the SQL migration (Step 1 of setup)

"Invalid credentials" when logging in
  → Admin user must be in Supabase Auth (not just database)
  → Check Authentication → Users in Supabase dashboard
  → Re-run create-admin script if needed

Images not loading
  → Verify image files exist in public/ folder
  → Check image paths in components

Stripe errors
  → Verify webhook is configured in Admin Settings
  → Check STRIPE_SECRET_KEY is set correctly

Email not sending
  → Verify RESEND_API_KEY is configured
  → Check email templates in Admin Settings

Database connection errors
  → Verify SUPABASE_URL and ANON_KEY are correct
  → Check network connectivity
  → Verify RLS policies allow access

For more help, see: SETUP_VERIFICATION.md
