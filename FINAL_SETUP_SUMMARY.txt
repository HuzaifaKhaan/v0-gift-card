Q: "relation does not exist" error?
A: Run the SQL migration from scripts/init-tables.sql

A: Make sure admin user was created in Supabase Auth (Authentication → Users)

Q: Getting hydration errors?
A: Already fixed! The app has suppressHydrationWarning configured.

Q: Stripe integration not working?
A: Check that STRIPE_SECRET_KEY and webhook are configured in Admin Settings

Q: Email not sending?
A: Verify RESEND_API_KEY is set and email templates are configured

For more troubleshooting, see the documentation files.
