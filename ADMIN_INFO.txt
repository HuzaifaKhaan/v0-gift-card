                         DATABASE SETUP REQUIRED
═════════════════════════════════════════════════════════════════════════════

Before you can log in, you need to:

STEP 1: Create Database Tables
───────────────────────────────────────────────────────────────────────────
  1. Go to https://app.supabase.com
  2. SQL Editor → New Query
  3. Copy: scripts/init-tables.sql
  4. Run the migration

STEP 2: Create Admin User in Supabase Auth
───────────────────────────────────────────────────────────────────────────
  Option A (Dashboard - Easiest):
    1. Authentication → Users → Create user
    2. Email: admin@lastminutecards.com
    3. Password: LastMinute@Admin2024
    4. Add user metadata: {"role": "admin", "full_name": "Administrator"}
    5. Create user

  Option B (Script):
    npx ts-node scripts/create-admin.ts

STEP 3: Start the Application
───────────────────────────────────────────────────────────────────────────
  npm install
  npm run dev

STEP 4: Log In
───────────────────────────────────────────────────────────────────────────
  http://localhost:3000/admin/login
  Email: admin@lastminutecards.com
  Password: LastMinute@Admin2024

═════════════════════════════════════════════════════════════════════════════
                        COMMON ADMIN TASKS
═════════════════════════════════════════════════════════════════════════════

Create a New Card Template
  1. Templates → Add New Template
  2. Fill in details (name, description, image)
  3. Set background and text colors
  4. Set price in cents
  5. Save

Customize Card Pricing
  1. Templates → Select template
  2. Click "Edit"
  3. Update price_cents
  4. Save

Add Another Admin User
  1. Settings → Admin Users → Add Admin
  2. Enter email and temporary password
  3. Email invitation to user
  4. User can change password on first login

Monitor Gift Card Status
  1. Cards → View All
  2. Filter by status (Claimed/Unclaimed)
  3. See sender and recipient info
  4. Click card for details

View Revenue
  1. Dashboard → Revenue section
  2. Or go to Analytics → Revenue Report
  3. Filter by date range
  4. Export data if needed

Configure Email Notifications
  1. Settings → Email → Email Templates
  2. Customize email templates
  3. Test sending email
  4. Enable/disable notifications
