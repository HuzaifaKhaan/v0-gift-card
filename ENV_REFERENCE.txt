================================================================================
                     HOW TO USE THESE VARIABLES
================================================================================

In frontend components (client-side):
  Only use variables starting with NEXT_PUBLIC_
  Example: process.env.NEXT_PUBLIC_SUPABASE_URL

In server components / API routes (server-side):
  Can use any variable
  Example: process.env.STRIPE_SECRET_KEY

In scripts:
  Can use any variable
  Example: process.env.SUPABASE_SERVICE_ROLE_KEY

In environment detection:
  Use: process.env.NODE_ENV

================================================================================
                      VERIFYING CONFIGURATION
================================================================================

To verify all variables are set correctly:
